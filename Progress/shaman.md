## 三、内部小工具（本职业自带）

本职业的决策层**自带一套内部小工具**（写在本文件顶部），
**不与其他职业共用** —— 改这个职业不会波及其它 8 个。

```python
class Ctx(object):                    # 读数打包
def _cd(spells, name): ...            # 取冷却值
def _ready(spells, name): ...         # CD == 0 的布尔简写
def _int(state, key, default=0): ...  # 安全取整数
def _is_enemy(目标类型): ...          # 敌对判定（区间 1~10）
def _in_melee(距离, yards=10): ...    # 距离在近战范围内
def _upkeep_ok(key, interval=3.0): ...  # 节流
def _reset_upkeep(): ...              # 清空节流状态
def _pick_dispel_unit(state_dict, 驱散开关, types): ...  # 挑驱散目标
```

**本职业实际带了这几个**：

| 小工具 | 作用 |
|--------|------|
| `Ctx` | 读数打包。属性：`combat/hp/mp/valid/target_type/target_hp/target_dist/target_casting/enemy_count/enemy5/auto_attack/dispel_switch/delay`；判断：`has_target/in_combat/melee`；方法：`cd(name)/ready(name)` |
| `_cd` | 取冷却值，缺失 → `255`（不可用） |
| `_ready` | `CD == 0` 的布尔简写 |
| `_int` | 安全取整数（缺失/非数字 → 默认值） |
| `_is_enemy` | 敌对判定（**区间** `1~10`，不要写 `== 1`） |
| `_in_melee` | 距离在近战范围内 |
| `_upkeep_ok` | 节流：维持类操作（补 buff/换武器）防重复按 |
| `_reset_upkeep` | 清空节流状态（换专精/重载时调） |
| `_pick_dispel_unit` | 从队友里挑要驱散的目标，返回 `(槽位, 单位数据)` |

> 没带的（比如本职业没有驱散技能就不带 `_pick_dispel_unit`）
> —— 工具段按实际用到的裁剪，不凑齐。

### 阈值常量

| 常量 | 当前值 | 含义 |
|---|---|---|
| `DISPEL_TYPES` | `(2, 3)` | 能驱散的减益类型（1魔法 2诅咒 3疾病 4中毒） |
| `HEAL_LOW` | `60` | 偏低血量 |
| `AOE_3` | `3` | 判定「AOE」的 5 码内敌人数门槛 |
| `AOE_5` | `5` | 判定「群体」的 5 码内敌人数门槛 |

**驱散技能**：`净化术`、`祛病术`（走动态宏 `@raidN`，按队友施放）

> 战斗中光环数据受限（读不到减益类型），会**盲驱血量最低的队友** ——机制见 README「十六点五、驱散机制」。

## 四、决策优先级

决策层 `Arasaka/class/shaman_logic.py` 的技能选择顺序：

**从上到下就是优先级** —— 第一个满足条件的技能直接返回，不再往下看。

| # | 技能 | 触发条件 | 限定专精 | 节流 |
|---|------|---------|---------|------|
| 1 | 净化术 | 有队友需要驱散 | — | — |
| 2 | 祛病术 | 有队友需要驱散 | — | — |
| 3 | 地震术 | 目标在施法 | — | — |
| 4 | 烈焰震击 | 目标在施法 | — | — |
| 5 | 冰霜震击 | 目标在施法 | — | — |
| 6 | 治疗链 | 队友槽位 is 非None 且 队友血量 is 非None 且 队友血量 ≤ HEAL_LOW 且 敌人数 ≥ AOE_3 | 恢复 | — |
| 7 | 治疗波 | 队友槽位 is 非None 且 队友血量 is 非None 且 队友血量 ≤ HEAL_LOW | 恢复 | — |
| 8 | 次级治疗波 | 队友槽位 is 非None 且 队友血量 is 非None 且 队友血量 ≤ HEAL_LOW | 恢复 | — |
| 9 | 治疗波 | 血量 ≤ HEAL_LOW 或 能量 ≤ 40 | 恢复 | — |
| 10 | 火焰新星 | — | 恢复 | 默认 秒 |
| 11 | 闪电链 | 敌人数 ≥ AOE_3 | 元素 | — |
| 12 | 闪电箭 | — | 元素 | — |
| 13 | 火焰新星 | — | 元素 | 默认 秒 |
| 14 | 风怒武器 | 5码内敌人数 ≥ AOE_3 | — | 20.0 秒 |
| 15 | 火舌武器 | — | — | — |
| 16 | 石化武器 | — | — | — |
| 17 | 冰封武器 | — | — | — |
| 18 | 火焰新星 | — | — | 默认 秒 |

> 「—」表示无条件（该分支里技能就绪就放）。
> 「节流」是 `upkeep_ok()` 的防抖间隔 —— 只给维持类操作用，主力技能没有。

### 条件里的字段对照

上表条件用的是 `Ctx` 的属性名，对应关系：

| 字段 | 含义 | 来源像素 |
|------|------|---------|
| `target_casting` | 目标正在施法 | `目标施法` |
| `target_hp` | 目标血量 % | `目标生命值` |
| `target_dist` | 目标距离（码） | `目标距离` |
| `enemy5` | 5 码内敌人数 | `5码敌人` |
| `enemy_count` | 敌人总数 | `敌人人数` |
| `hp` | 自己血量 % | `生命值` |
| `mp` | 自己能量 % | `能量值` |

`AOE_3` / `AOE_5` / `EXECUTE_HP` 等是**本地常量**（见上文「阈值常量」），不在像素里。
